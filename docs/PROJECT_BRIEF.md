# Product brief — Sentinel Explorer Web

## 1. Назначение
Sentinel Explorer Web — браузерное геопространственное приложение для поиска, просмотра, визуализации и последующего анализа Sentinel-2. Это отдельный продуктовый интерфейс, развивающий сценарии существующего плагина. Это не только лендинг и не механическое копирование кода плагина.

## 2. Пользователи
- Пользователь ГИС, которому нужно найти и просмотреть Sentinel-2.
- Специалист по лесам и природным территориям.
- Пользователь, который хочет быстро менять спектральные композиции.
- Пользователь в России, которому нужен доступ к приложению и материалам без VPN.

## 3. Основной сценарий MVP
1. Открыть приложение.
2. Выбрать территорию прямоугольником на карте или задать bbox.
3. Указать даты и максимальную облачность.
4. Найти Sentinel-2 L2A.
5. Просмотреть список сцен с датой, облачностью, ID и покрытием.
6. Выбрать сцену и открыть реальное изображение на карте.
7. Назначить B02/B03/B04/B08 на R, G, B произвольным образом.
8. Настроить растяжение и gamma.
9. Экспортировать AOI в GeoTIFF с выбранными каналами.
10. Повторно открыть просмотренный материал быстрее за счёт кэша.

## 4. Обязательные требования

### Данные
- MVP online: Sentinel-2 L2A.
- Базовые каналы: B02, B03, B04, B08.
- Произвольное назначение каждого канала на R/G/B; фиксированные пресеты не заменяют селекторы.
- Рабочие результаты должны быть получены из каталога/файлового источника, не из статических карточек.
- Учитывать geometry, CRS, nodata, scale/offset и фактическую доступность assets.
- Для просмотра использовать тайлы или потоковую выборку; не скачивать весь исходный GeoTIFF в браузер ради отображения.

### Доступ из России
- Сайт, API, каталог, растровые файлы и скачивание — разные сетевые зависимости.
- Основная инфраструктура и кэш — в российском дата-центре.
- Браузер обращается к домену приложения, не к upstream хранилищам.
- Доступность upstream с российского сервера проверяется фактически.
- Если источник или его условия не разрешают репликацию/выдачу, не маскировать это проксированием; выбрать разрешённый источник или согласованный способ распространения.
- Фраза «работает без VPN в России» допустима только после тестов по DATA_ACCESS_RUSSIA.md.

### ГИС
- Карта, pan/zoom, AOI selection.
- В перспективе — внешние векторные слои и просмотр атрибутов.
- В перспективе — локальные растры и векторы.
- Редактирование векторов необязательно; просмотр атрибутов важен.
- Офлайн для заранее сохранённых материалов с учётом ограничений браузера.

### Надёжность и безопасность
- Ошибки источников видимы пользователю и попадают в лог.
- Длинные операции — фоновые jobs.
- Загрузка проверяет целостность и поддерживает resume, где возможно.
- Секреты поставщиков никогда не попадают во frontend.
- Произвольный URL пользователя нельзя передавать серверному загрузчику без allowlist и защиты SSRF.

## 5. Не входит в MVP
- Автоматическая классификация лесных нарушений.
- ML-модель для вырубок/ветровалов.
- Глобальное зеркало всей коллекции Sentinel-2.
- Многопользовательская система организаций/ролей.
- Полное редактирование геометрии.
- Нативная мобильная оболочка.
- NBR на базовом четырёхканальном профиле.
- Полный оригинальный SAFE-продукт каждой сцены до проверки источника, прав и объёмов.

## 6. Перспективы
- NDVI.
- Дополнительные каналы по отдельному решению, SWIR для NBR.
- Сравнение двух дат, swipe before/after.
- Предварительное выделение изменений.
- ФГИС ЛК/SOLI и атрибуты лесных объектов, если API подтверждён.
- Обучающие выборки для лесного мониторинга.
- Офлайн-пакеты.

## 7. Географический пилот
Пермский край; интерес — хвойные и смешанные леса, вырубки, ветровалы и другие нарушения. В перспективе — несколько тестовых площадок, затем территории порядка 1 000–5 000 км². Это не означает, что всю область нужно предварительно скачивать.

## 8. Разделение статусов
- Existing — подтверждённый факт о текущем плагине/репозитории.
- Planned — функция планируется, но не реализована в браузерном приложении.
- Verified — поведение подтверждено тестом конкретной сборки и отчётом.

Не называть функцию реализованной в веб-приложении до появления кода и прохождения тестов.
