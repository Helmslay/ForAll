# Landing page — GIS-first redesign

## LP-01 — переработка публичного лендинга
**Статус:** DONE.  
**Зависимости:** нет; независимая презентационная задача, не меняет последовательность WEB-01.04.  
**Цель:** обновить публичную страницу Sentinel Explorer так, чтобы она представляла продукт как профессиональную браузерную ГИС и честно отражала текущее состояние разработки.

### Scope
- Переработать только публичный `index.html`.
- Сделать карту и геопространственные сценарии главным визуальным акцентом.
- Показать концептуальное рабочее пространство с явно обозначенной схематичной картой, без имитации реального спутникового снимка.
- Добавить интерактивную демонстрацию назначения B02/B03/B04/B08 на RGB; она меняет только подпись композиции и не должна изображать реальную обработку данных.
- Сохранить адаптивность, семантическую структуру, клавиатурный фокус и поддержку `prefers-reduced-motion`.
- Исправить формулировки о готовности: браузерная карта, каталог, imagery и backend пока не реализованы.
- Добавить лёгкую CI-проверку структуры, навигации и трёх RGB-селекторов.

### Не входит
- Изменение frontend-приложения в `app/`.
- Реализация карты, API, каталога, обработки или загрузки снимков.
- Обещания доступности без VPN или неподтверждённых функций.
- Изменение архитектуры и API-контрактов.

### Проверки и критерии приёмки
- HTML5 document, `lang=ru`, один H1 и семантические header/nav/main/footer.
- Все внутристранчные ссылки ведут на существующие ID; ID уникальны.
- Три независимых RGB-селектора содержат все четыре разрешённых канала.
- Есть адаптивный breakpoint и обработка reduced motion.
- Концептуальная карта и демонстрация RGB явно помечены как макет, а не реальные данные.
- Текст о текущем состоянии соответствует `docs/STATUS.md`.
- GitHub Actions landing checks проходят.

### Результат выполнения (2026-11-17)
- Лендинг перестроен вокруг карты, ГИС-сценариев и четырёх каналов Sentinel-2; визуальный язык стал более сдержанным и инструментальным.
- Схематичная карта явно маркирована как концепция; три селектора RGB интерактивны и меняют только текстовое обозначение композиции.
- Удалены утверждения о якобы готовой браузерной функциональности. Статус отражает фактический frontend scaffold и ещё не реализованные карту/backend/catalog/imagery.
- Добавлены мобильная навигация, семантические landmarks, focus states и reduced-motion support.
- **Изменённые файлы:** `index.html`, `.github/workflows/landing-check.yml`, `docs/tasks/LANDING_PAGE.md`, `docs/EXECUTION_PLAN.md`, `docs/STATUS.md`.
