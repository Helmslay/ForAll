# WEB-08.00 — read-only preflight текущего VPS для изолированного публичного demo

**Статус:** READY  
**Зависимости:** WEB-01.10 — DONE; WEB-01.11 — DONE.  
**Цель:** определить, подходит ли существующий VPS `195.208.123.209` для отдельного публичного demo текущего frontend/backend scaffold без влияния на Sentinel Explorer Agent.

## Scope
- Выполнить только read-only инвентаризацию ОС, CPU, RAM, диска, активных служб, слушающих TCP-портов и текущего состояния агента.
- Оценить доступный ресурс с учётом уже работающего агента; не считать прежние показатели памяти/диска актуальными без повторного измерения.
- Проверить наличие Docker Engine/Compose и reverse proxy, не устанавливая и не включая их.
- Зафиксировать, какие DNS/domain/TLS предпосылки нужны для публичного HTTPS.
- По результатам выбрать один из выводов: текущий VPS подходит для облегчённого demo; подходит только после согласованного изменения ресурсов/конфигурации; не подходит — нужен отдельный VPS.

## Безопасность и ограничения
- Не устанавливать пакеты, контейнеры или службы.
- Не менять firewall, SSH, DNS, systemd, пользователей, права, конфигурацию и порты.
- Не перезапускать и не останавливать агент.
- Не читать и не выводить токены, `agent.env`, приватные ключи, env-файлы или содержимое секретов.
- Не выполнять сетевые сканирования внешних адресов.
- Не запускать frontend/backend и не открывать публичный доступ в рамках этой задачи.
- Не выполнять `docker system prune`, очистку кэшей или удаление файлов.

## План проверки
1. Зафиксировать дату/время, hostname и версию ОС.
2. Получить CPU/RAM/swap/disk usage и filesystem availability.
3. Получить список активных systemd services и слушающих TCP sockets.
4. Проверить статус `sentinel-explorer-agent.service` и его ограничения systemd без изменения службы.
5. Проверить наличие Docker/Compose/Nginx/Caddy командами обнаружения, не устанавливая их.
6. Сформировать краткий отчёт с фактическими значениями и рекомендацией по допустимому варианту demo.

## Критерии приёмки
- Отчёт получен с текущего VPS и содержит фактические CPU, RAM, swap, disk, services, ports и наличие runtime компонентов.
- Подтверждено, что агент остался active и его конфигурация не менялась.
- Нет секретов, токенов, приватных ключей и содержимого env-файлов в отчёте.
- Есть обоснованный вывод о возможности размещения отдельного demo на этом VPS.
- Ни одна системная настройка не изменена.

## Не входит
- Создание production Docker images/Compose.
- Установка Nginx/Caddy, настройка HTTPS/DNS/firewall.
- Публичное развёртывание, открытие портов и изменение конфигурации VPS.
- Реализация карты, каталога, Sentinel API или raster viewer.
- Заявления о доступности Sentinel-2 или работе без VPN.

## Результат
Ожидает выполнения read-only команд на VPS. До получения отчёта нельзя утверждать, что текущий сервер подходит для публичного demo.
