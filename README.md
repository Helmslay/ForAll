# Sentinel Explorer — landing page

Промо-страница плагина Sentinel Explorer.

## Локальный просмотр

Откройте `index.html` в современном браузере. Сайт не требует сборки, npm-пакетов или серверной части.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
4. После завершения публикации GitHub Pages покажет адрес сайта в этом же разделе.

## Содержание страницы

- Возможности текущей версии Sentinel Explorer.
- Пошаговый сценарий работы со сценами Sentinel-2.
- Используемые каналы B02, B03, B04 и B08.
- Отдельное разделение реализованных функций и направлений развития.
- Дорожная карта: спектральные индексы, анализ изменений, лесной мониторинг, интеграция ФГИС ЛК / SOLI и офлайн-сценарии.

## Примечание о статусе

Раздел «Реализовано» описывает известные работающие сценарии проекта. Некоторые режимы и совместимость могут зависеть от версии плагина. Дорожная карта обозначает направления развития и не является обещанием сроков выпуска.

Иллюстрация интерфейса на лендинге — концептуальный макет, не скриншот действующей версии.
